# TỔNG HỢP 600 KỊCH BẢN ĐẦU VÀO (INPUT-600)
Hệ thống kịch bản lâm sàng chuẩn hóa cho 60 bệnh lý khởi phát với triệu chứng đau.
Dựa trên tài liệu y khoa chính thống: `tong_hop_60_benh_khoi_phat_dau.md` (Bộ Y tế QĐ 361, Vinmec, MSD Manuals).

## Cấu trúc lưu trữ:
- **6 Nhóm chuyên khoa:**
  1. `nhom_1_co_xuong_khop_day_chang/` (30 bệnh lý, 300 kịch bản)
  2. `nhom_2_than_kinh/` (8 bệnh lý, 80 kịch bản)
  3. `nhom_3_tieu_hoa_gan_mat/` (7 bệnh lý, 70 kịch bản)
  4. `nhom_4_tim_mach_ho_hap/` (6 bệnh lý, 60 kịch bản)
  5. `nhom_5_tiet_nieu_phu_khoa/` (5 bệnh lý, 50 kịch bản)
  6. `nhom_6_tai_mui_hong_mat_rhm/` (4 bệnh lý, 40 kịch bản)
- **Tổng cộng:** 60 file `.md` chi tiết tương ứng 60 bệnh lý + 6 file tổng hợp nhóm `.md` = **600 kịch bản lâm sàng đầy đủ**.

## Mỗi kịch bản bao gồm 4 phần chuẩn mực:
1. **Tình huống lâm sàng:** Hoàn cảnh phát bệnh, công việc, sinh hoạt và lý do đi khám.
2. **Triệu chứng điển hình:** Miêu tả cảm giác đau thuần Việt (buốt nhói, ê ẩm, cứng ngắc...), tuân thủ nghiêm ngặt quy tắc người bệnh không nói tên giải phẫu chuyên khoa.
3. **Persona Bác sĩ:** Tên tuổi, chuyên khoa, phong cách giao tiếp ân cần, thăm khám nhẹ nhàng, giải thích cặn kẽ, nói câu ngắn gọn (dưới 20 từ).
4. **Persona Bệnh nhân:** Tên tuổi (20 - 80 tuổi), nghề nghiệp đa dạng, các cặp giới tính phối hợp đầy đủ (Nam-Nam, Nam-Nữ, Nữ-Nam, Nữ-Nữ), tâm lý lo âu/thật thà và khẩu ngữ đời thường.
